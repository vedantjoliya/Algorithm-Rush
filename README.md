# 🚀 Algorithm Rush

**Master the Algorithm. Go Viral.**

Algorithm Rush is a modern multiplayer strategy board game inspired by social media growth, viral content, and platform algorithms. Players compete to become the first creator to reach **100,000 followers** by navigating growth opportunities, viral trends, algorithm changes, and unexpected setbacks.

## 🎮 Live Demo

https://algorush.gamer.free/

---

## 🌟 Features

### Multiplayer Gameplay

* Support for 2–4 players
* Custom player names
* Turn-based gameplay
* Interactive dice rolling mechanics

### Dynamic Board System

* 40 unique board spaces
* Multiple gameplay zones
* Growth spaces
* Penalty spaces
* Algorithm event spaces
* Viral boost spaces

### Algorithm Cards

Over 15 unique event cards including:

* Trending Audio
* Brand Deals
* Influencer Shoutouts
* Shadow Bans
* Copyright Strikes
* Viral Challenges
* Platform Updates
* Collaboration Bonuses

### Viral Mode System

* Build viral momentum
* Activate Viral Mode
* Double follower gains
* Temporary immunity from penalties
* Strategic risk and reward mechanics

### Responsive Design

* Mobile-friendly interface
* Tablet support
* Desktop optimized experience
* Modern UI powered by Tailwind CSS
